# One Solutions — Premium Services Redesign

The services section has been redesigned as a visual showcase rather than a simple five-link navigation bar.

Each service now has:
- A premium dark 3D card
- Dedicated animated visual
- Service number and category
- Short clear value proposition
- Micro-metric / feature chips
- Hover tilt and depth
- Animated AI orbit, CRM pipeline, marketing bars, analytics ring and ERP module grid
- Active-state highlighting as the visitor scrolls through the detailed service sections

The detailed top-to-bottom service sections remain below the showcase.

The hero video, pricing, currency detection and other previous functionality are preserved.
